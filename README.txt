Ponzu Studio Works - Corporate Website Package
=============================================

Contents
--------
- index.html
- assets/css/style.css
- assets/js/script.js
- assets/images/hero.png
- assets/images/operations.png
- assets/images/team.png

How to use
----------
1. Upload all files in this folder to your repository root.
2. If you use GitHub Pages, place index.html at the repository root.
3. Replace the placeholder email address `your-email@example.com` in index.html.
4. Update company profile fields as needed.
5. Commit and push.

Notes
-----
- All site images in assets/images were AI-generated for this website package.
- The site is a static HTML/CSS/JS website and is responsive.
